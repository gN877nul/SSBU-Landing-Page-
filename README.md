# Super Smash Bros. Ultimate — Landing Page

Sitio web informativo inspirado en **Super Smash Bros. Ultimate**, creado como proyecto académico. Presenta una página de inicio con información del juego, un carrusel de luchadores y una sección de modos de juego.

## Características

- Navegación por secciones: juego, luchadores y modos.
- Carrusel horizontal de personajes con controles interactivos.
- Diseño adaptable a distintos tamaños de pantalla.
- Botón que dirige al sitio oficial de Super Smash Bros.

## Tecnologías

- ASP.NET Web Forms con C#
- .NET Framework 4.7.2
- HTML, CSS y JavaScript
- Visual Studio e IIS Express para ejecución local

## Requisitos

- Windows
- Visual Studio con la carga de trabajo **Desarrollo de ASP.NET y web**
- .NET Framework 4.7.2 Developer Pack

## Cómo ejecutar

1. Clona o descarga este repositorio.
2. Abre `Actividad final programascion 4.slnx` en Visual Studio.
3. Si Visual Studio lo solicita, restaura los paquetes NuGet.
4. Ejecuta el proyecto con IIS Express desde Visual Studio.

## Estructura

```text
Actividad final programascion 4/
├── Default.aspx              # Página principal
├── Default.aspx.cs           # Código C# de la página
├── Styles/estilo.css         # Estilos
├── Scripts/script.js         # Interacción del carrusel
└── Images/                   # Recursos gráficos del proyecto
```

Las imágenes de algunos luchadores se cargan desde el sitio oficial de Super Smash Bros.; por ello, esas imágenes requieren conexión a Internet.

## Créditos

Proyecto académico de fans. **Super Smash Bros.** y sus personajes pertenecen a sus respectivos titulares; esta página no es un producto oficial de Nintendo.
